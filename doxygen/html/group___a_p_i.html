Detailed Description

Functions exposed to run the algorithm in different settings. Briefly, setStep() will leave the object ready for a step, setCycle() will perform each cycle of the step and isStepFinished() will inform whether the conditions for ending the step have been met. When used with a graphical interface, bl.refreshScreen.isMax() is true after a given number of cycles after the last true value. It can be used to avoid drawing each step.

Thus, if bl is an exported borderLine object, 

 <pseudocode>
  for step in 1:7
   setStep(step)
   quit = false
   while !quit
     setCycle(step)
     if bl.refreshScreen.isMax()
       draw_svg_result
     if isStepFinished(step)
       quit = true
  </pseudocode>
